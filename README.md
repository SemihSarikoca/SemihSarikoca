### 🔍 [CrackDetection](https://github.com/SemihSarikoca/CrackDetection)
A modular crack detection toolkit with a **hand-crafted, multi-scale Canny edge detector** — bilateral denoising, Sobel gradients, NMS, hysteresis thresholding, and connected-component analytics. All processing stages implemented from scratch with NumPy, no off-the-shelf CV libraries.

`Python` `Image Processing` `Computer Vision` `NumPy`

### 🛰️ [SecureShell](https://github.com/SemihSarikoca/SecureShell)
A **secure shell interface** designed for satellite communication devices. Features a Textual-based TUI, REST API with Flask, Docker simulation environment, and remote deployment via rsync. Built with Python 3.14's no-GIL mode for true concurrency.

`Python` `Flask` `Docker` `Textual TUI`
